## 推荐演示路线

1. 在“运营概览”查看 28 条订单、已支付金额、支付事件和待投递 Outbox 数量。
2. 打开“订单中心”，选择一条“待支付”订单并点击“模拟支付”。
3. 刷新后再次对同一订单操作，说明支付事件 ID 和唯一约束用于幂等。
4. 对“已支付”订单点击“预占库存”，观察状态变为“已预占”、库存可用量减少。
5. 继续执行“确认发货”和“完成”，说明服务层状态机拒绝越级流转。
6. 打开“事件中心”，查看同一事务写入的 `PaymentConfirmed`、`InventoryReserved` 和 `OrderStatusChanged` 事件。
7. 刷新浏览器验证数据仍在云端 MySQL 中。

## 数据说明

初始化器只补充缺失的稳定业务键，不删除已有数据。容器重建后重新连接同一 MySQL，已操作的订单和事件仍会保留。
